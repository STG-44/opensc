# Project collaboration preferences

- Work in `main` and push completed, validated changes to GitHub directly. The user authorized immediate GitHub publication on 2026-11-06; do not ask again for routine commits, pushes, PR consolidation or merges needed to keep the work in `main`.
- Consolidate existing branches into `main`. Remove obsolete branches only after their changes are preserved in `main`; preserve local worktree files and unpublished work.
- GitHub-facing content must be in English. Localization resources use their target languages.
- Deployments to the game/update server and public binary releases still require a separate explicit instruction. GitHub publication alone does not authorize changing Stable/Test server channels.
- Keep original game assets private and unchanged; use the asset override system for replacement resources. Do not commit private transfer archives, original assets or conversation exports.
