# Кусачки, разрезание сетки и пролезание

После третьего часового подбери **Fence Cutters** ЛКМ. Кусачки уже лежат на карте в исходной позиции MTF и доступны с начала обучения. Они автоматически становятся основным предметом; нож, BDA и оставшиеся патроны сохраняются в инвентаре. Space открывает инвентарь, где можно менять основной предмет перетаскиванием.

Выбери Джона и щёлкни ЛКМ по учебной сетке **AlStFn-Consertinafence_END**. Боец подходит к ближайшей точке действия, берёт кусачки и выполняет две исходные анимации. В кадре callback разрезания закрытая сетка заменяется оригинальной моделью с отверстием. Затем callback второй анимации возвращает последнее запомненное основное оружие. Его выбор обновляется при подборе кусачек и последующих переключениях на нож или BDA. Точная логика выбора этого предмета в старом EXE ещё не подтверждена.

**Повторный ЛКМ по этой же сетке** задаёт пролезание. Джон подходит к отверстию и пересекает его в низкой ползущей позе; пересечение работает в обоих направлениях. H или другой приказ отменяют действие. Если разрез уже выполнен, отмена оставляет проход открытым. Пауза, паузящая подсказка и инвентарь останавливают действия. Home возвращает исходную сетку и лежащие кусачки вместе со сбросом обучения.

Эти события не завершают четвёртую основную задачу: после разреза и пролезания выполнены **три из шести** задач обучения. Help 10 предлагает приседание и UZI; [стойки и следующая группа охраны](SMG-RU.md) подключены. Четвёртая задача завершается после всей группы, а не после разреза.

## Столкновения и границы точности

Все пять объектов карты, отнесённых `object_templates.txt` к `Structure_Fence`, блокируют прямое движение по своим исходным нижним SMF bounds. Проверяется весь отрезок шага с радиусом бойца 0.20 м, поэтому большой шаг также останавливается перед закрытым ограждением. После разреза только выбранная сетка получает две боковые границы cut-модели. Центральное отверстие пропускает движение.

Это проверка на уровне земли: высота тела, верхняя перекладина, двери, здания, вода и общий поиск обходного маршрута пока не учитываются. Приказ к недоступной точке останавливается у сетки. Геометрия отверстия исходная; правило выбора replacement-модели и смысл `Act01/Act02` в EXE ещё не восстановлены. Радиус 0.20 м и нормирование корневой траектории между точками прохода — временные правила проекта. Звук резания не восстановлен.

Оригинальная модель, положения и повороты читаются через `AssetCatalog`, поэтому overrides применяются к ним и к конфигурации последовательностей. Неверный callback, неподдержанный слот/стиль, число повторов и повреждённая модель возвращают ошибку до запуска окна. Исходные файлы игры не изменяются.

## Запуск проверки

```bash
# Вся цепочка нож → BDA → граната → кусачки → разрез → проход, без окна:
./scripts/dev.sh cargo run --locked -p shadow-model-viewer --bin shadow-map-viewer -- \
  --game-dir "/путь/к/игре" --player on --player-action fence \
  --player-seconds 240 --player-json /tmp/fence.json

# Та же цепочка с приказами мышью в окне:
./scripts/dev.sh cargo run --locked -p shadow-model-viewer --bin shadow-map-viewer -- \
  --game-dir "/путь/к/игре" --window 1280x720 \
  --fence-smoke-json /tmp/fence-window.json --screenshot /tmp/fence-window.png
```

## Для изучения Rust и Bevy

В `fence.rs` проследи `order_fence → Phase → update → Tutorial::fire → sync`. Enum `Phase` разделяет подход, резание, смену предмета и пролезание; `Option<Phase>` означает отсутствие приказа. Сравни временные callback с отдельным постоянным флагом `cut`: отмена анимации не откатывает уже открытый проход.

`repeat_crawl` складывает перемещение корня на границах пяти циклов, а `Box2::hit` пересекает отрезок с расширенной коробкой в локальных координатах SMF. `sync` переключает видимость исходной сетки, cut-модели и подобранного предмета, используя раздельные запросы Bevy. Попробуй объяснить, почему корневая траектория без накопления давала бы шаг назад на каждом повторе. [Результаты проверок](VALIDATION-RU.md).
