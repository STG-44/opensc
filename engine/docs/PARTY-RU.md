# Спасение Джека и два бойца

После посадки в Hummer активируется шестая задача. Остановись у загона Джека, выйди из машины и открой ворота. ЛКМ по Джеку при выбранном Джоне задаёт подход. На дистанции разговора Джек произносит исходную реплику, присоединяется к команде, задача завершается и появляется help_combat_18.

## Управление

- **1 / 2** — выбрать Джона / Джека. **F9 / F10** переключают выбор, **F11** выбирает обоих. Эти клавиши сверены с `config/keyboard_defs.txt`; клавиша 3 сохраняется для будущего третьего бойца.
- **ЛКМ по бойцу** выбирает его, **Ctrl+ЛКМ** добавляет или убирает его из группы. Доступны также исходные портреты Джона и Джека и клавиша F11.
- **ЛКМ по земле** задаёт движение выбранному бойцу; для обоих назначаются отдельные конечные точки. Двойной ЛКМ включает бег. **H** останавливает выбранных, **T** включает слежение, **S/C/P** меняют стойку.
- **Ctrl+P** приостанавливает обоих, сценарий и реплику; **Esc** в основном приложении открывает меню. **Home** возвращает Джона, Джека, ворота, снаряжение и задания к началу.

Состояние движения, скелет, выбор, анимация и положение у бойцов раздельные. Инвентарь, оружие, броня и аптечка Джона сохраняются при переключении. Джек пока поддерживает движение и стойки; предметные действия, стрельба, лечение, броня и посадка Джека в машину ещё не подключены. Для инвентаря и управления Hummer выбери Джона. Движение группы сейчас предназначено для бойцов на земле.

[Рамка выделения и оригинальные портреты](SELECTION-RU.md) подключены. [Эвакуация дымовым сигналом и завершение обучения](EVACUATION-RU.md) подключены. Исходная help_combat_18 описывает также групповой выбор и эвакуацию. У бойцов нет обхода препятствий: через узкий проход их удобнее провести по очереди. Групповой приказ использует временное смещение конечных точек до одного метра, а не восстановленную систему построений оригинала.

## Исходные ресурсы

Jack, ID **[8,-632]**, принадлежит `LOCAL_SCRIPTED AI_Prisoner`, менеджер **8**. Исходная позиция MTF — **[2386.83349609375,2831.8212890625,1210]**, поворот `[0,0,0]`; в Bevy это примерно **[23.8683,12.1,-28.3182] м**. Модель тела `Man6_TP`, голова `Head_Jack`, текстуры и Smallpack читаются из `config/character_profiles/jack_beecher.txt`. Исполняемый файл оригинала для запуска движка не нужен.

Дистанция `oli_converse_range` берётся из `config/perception_var_defs.txt`: **400 исходных единиц = 4 м**. В прототипе дополнительно требуется активная шестая задача, Джон вне машины и свободный отрезок до Джека по ограждениям/воротам и сплошной геометрии. Так разговор не запускается через закрытое ограждение. Эти условия допуска не выдаются за полностью восстановленную систему восприятия оригинала.

Разговор `beecher_reporting_for_duty` содержит один `CONVERSE_ELEMENT Jack Atg_02.wav`. `SOUND_DIR Jack` определяет `sounds/speech/jack/atg_02.wav`. В имеющейся установке это PCM, моно, 8 бит, 11025 Гц, около **1.113 с**. Внешность и звук допускают замены через общий каталог. Для жеста используется исходная `MSEQ_STAND_CONVERSE_1`; выбор именно этого жеста нашим контроллером пока не подтверждён как полный алгоритм выбора анимации старого EXE.

## Как трактуются задержки CER

Файл содержит 200, 10000, 2000 и 1000 мс для разговора, цели, передачи управления и подсказки. Они **не складываются в общую последовательность ожидания**. Это проверено по восстановленному `shadow.exe`:

- `0x44910e–0x44913b`: `CER_BODY_MS_DELAY` распознаётся по хешу `0x37c92154` и сохраняется в поле `0x10`.
- `0x4431e0–0x443259`: тело CER обходит действия без накопления общего времени.
- `0x449505 → 0x4065b0 → 0x44a2f0`: запуск разговора не использует поле задержки.
- `0x449611`: завершение задачи без звука вызывается сразу.
- `0x449781`: передача управления вызывается сразу, без чтения поля задержки CER.
- `0x449588`: показ контекстной подсказки передаёт значение поля `0x10` в очередь сообщений.

Поэтому в этом обработчике разговор, шестая задача и управление исполняются сразу, подсказка — через 1000 мс. Удаление подписки не удаляет назначенную подсказку. Для прочих обработчиков сохранено прежнее ограничение одной ненулевой задержки и поддержанного набора действий: общий интерпретатор кампании ещё не реализован.

## Код и проверка

`party.rs` хранит отдельный `Player` Джека, создаёт его собственные Root/Bone-компоненты, исполняет проверку сближения, управляет выбором и звуком. `tutorial.rs` выдаёт подтверждённые внешние действия через очередь; предметные системы Джона получают условие запуска по его выбору. Столкновения с сетками и воротами применяются к каждому бойцу отдельно.

Из папки проекта:

```bash
./scripts/dev.sh cargo run --locked -j1 -p shadow-model-viewer --bin shadow-map-viewer -- \
  --game-dir "/путь/к/Shadow Company" --player on --window 1280x720 \
  --player-action vehicle --player-seconds 480 \
  --jack-smoke-json /tmp/shadow-jack.json --screenshot /tmp/shadow-jack.png
```

Проверка создаёт состояние после предыдущих учебных действий и посадки в Hummer, выполняет допустимый выход, затем переносит Джона к исходным воротам. Дорога на машине не считается пройденной этим тестом. Дальше используются клики по воротам и Джеку, пауза, отдельное движение Джека, кнопка выбора Джона, F11 и движение группы, затем Home. Ввод проверяется через Bevy ButtonInput и viewport rays; физическую мышь и звук через реальные колонки следует проверять вручную.
