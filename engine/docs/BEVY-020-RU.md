# Bevy 0.20

Проект закреплён на **Bevy 0.20.0** через общую зависимость workspace и `Cargo.lock`. Rust остаётся **1.99.0**. Обновлены все приложения: игра, карта, персонаж, модель и просмотрщик изображений.

Основа перехода — [официальное руководство 0.19 → 0.20](https://bevy.org/learn/migration-guides/0-19-to-0-20/). Исходники старых `bevy::ui::Button` и `Interaction` заменены: `UiButton` требует новый `bevy::ui_widgets::Button`, `Node`, `Hovered` и состояние интерфейса проекта. Система `ui_controls::sync` читает `Hovered` и наличие `Pressed` перед обработкой ввода. Это сохраняет общий путь для меню, OK подсказок и перетаскивания инвентаря. Неизменившееся состояние не помечается изменённым каждый кадр.

Декоративные тени и значки используют `Pickable::IGNORE`: новый picking не учитывает прежний `FocusPolicy`.

`ui` уже включает плагины новых кнопок и picking. Существующие клавиши меню продолжают действовать через системы проекта. Проверка `modern_button_pointer_events_reach_project_state` посылает настоящие `PointerPress`/`PointerRelease` в `ButtonPlugin`; это проверяет соединение нового API с нашими действиями. Автоматическая проверка инвентаря в графическом окне отдельно подставляет состояние кнопок проекта: она не заменяет ручную проверку физического перетаскивания мышью.

Рендеринг остаётся через **wgpu**, теперь версия **30.0.1** в lock-файле. При местном запуске проверяется Vulkan на программном адаптере llvmpipe. Тесты на CachyOS не означают, что уже проверены аппаратные GPU, Windows или macOS; матрица CI и границы поддержки описаны в [PLATFORMS-RU.md](PLATFORMS-RU.md).

Сборка и проверки:

```bash
./scripts/dev.sh cargo test --workspace --locked -j1
./scripts/dev.sh cargo clippy --workspace --all-targets --locked -j1 -- -D warnings
./scripts/dev.sh cargo fmt --all --check
./scripts/demo-game.sh
```

Текущие результаты находятся в [VALIDATION-RU.md](VALIDATION-RU.md). Записи предыдущих этапов на 0.19.1 сохранены как история; свежие проверки 0.20 перечислены отдельно.
