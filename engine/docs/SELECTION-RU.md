# Рамка выделения и портреты

Потяни ЛКМ по свободной области карты: зелёная рамка выбирает Джона и присоединившегося Джека. **Ctrl + рамка** добавляет бойцов к текущему выделению. Пустая рамка без Ctrl снимает выделение. Обычный щелчок по миру исполняется при отпускании ЛКМ; двойной щелчок по земле сохраняет бег. Начало рамки не задаёт движение и не отменяет уже выданные приказы.

Портрет Джона доступен с начала обучения, портрет Джека появляется после спасения. ЛКМ выбирает бойца, Ctrl+ЛКМ меняет состав группы, F11 выбирает всех доступных бойцов. Двойной ЛКМ по портрету переводит камеру к бойцу. ПКМ по портрету Джона открывает его инвентарь, если он вне машины; ПКМ по Джеку выбирает Джека. Собственный инвентарь Джека ещё предстоит. Под портретом Джона показана полоса здоровья.

ПКМ отменяет начатую рамку. Открытие инвентаря, подсказки или меню паузы, Home, потеря фокуса окна и выход курсора из окна также отменяют жест. Панели отряда, машины и эвакуации перехватывают ЛКМ всей своей площадью. Портреты находятся в исходной нижней полосе; управление выходом из машины размещается рядом с ними.

## Исходные данные и замены

Профили `config/character_profiles/john_emerson.txt` и `jack_beecher.txt` содержат `BOTTOM_BAR_FACE 3 0` и `BOTTOM_BAR_FACE 2 4`. `config/image_defs.txt` описывает `merc_faces_3` и `merc_faces_2`: исходный размер страницы 128×128, размер кадра 42×64. Джон занимает `[0,0,42,64]`, Джек — `[42,64,84,128]`. Изображения разрешаются каталогом ресурсов, сейчас это `textures/object/characters3.bmp` и `characters2.bmp`.

Читается поддержанное описание `ANIMSPRITE3D` с `FRAMEDESCRIPTOR` и `SPRITEFRAME_XRUN`. Ошибочные индексы, размеры, количество кадров и неподдержанные команды дают понятную ошибку загрузки. Это загрузчик нужных атласов портретов, общий проигрыватель всех ANIMSPRITE ещё предстоит.

Профиль, `image_defs.txt` и сами текстуры можно заменить через `--overrides`. Если заменить атлас изображением большего размера, координаты кадров масштабируются относительно исходной страницы. Соотношение сторон портретов в интерфейсе сохраняется. Шрифты — Unicode, подписи не нарисованы внутри старых картинок.

## Устройство и ограничения

`selection.rs` хранит жест от нажатия до отпускания. Порог начала рамки — **6 логических пикселей**, одинаковых при изменении DPI; значение выбрано для прототипа. Короткий жест возвращает существующим обработчикам одно событие щелчка с координатами начала. При рамке выбираются экранные проекции центра тела доступных бойцов, а не пересечения всей геометрии. Закрытие другими 3D-объектами пока не учитывается. Джон внутри Hummer рамкой не выбирается.

`roster.rs` отдельно читает профиль и атлас, создаёт `ImageNode` с прямоугольником кадра и обновляет оформление выбора. Бойцы сохраняют собственные позиции, назначения, анимацию и снаряжение при изменении выделения. При возврате в меню панель и оба изображения освобождаются вместе с учебной сценой.

Размещение портретов теперь берётся из нижней панели оригинала и адаптируется к 16:9 и 21:9; см. [HUD-RU.md](HUD-RU.md). Порог рамки выбран для прототипа. Наличие рамки, портретов, выбора и перехода камеры сверено с исходными учебными подсказками; точное воспроизведение всех деталей интерфейса старого EXE не заявляется.

## Проверка

```bash
./scripts/dev.sh cargo run --locked -j1 -p shadow-model-viewer --bin shadow-map-viewer -- \
  --game-dir "/путь/к/Shadow Company" --window 1280x720 \
  --selection-smoke-json /tmp/shadow-selection.json --screenshot /tmp/shadow-selection.png
```

Проверка в нативном окне сначала дожидается первой учебной подсказки и закрывает её, затем переносит Джека рядом с Джоном как фикстуру, проверяет четыре направления рамки, запрет выбора до присоединения, Ctrl, пустую рамку, отмену, панели, портреты и Home. Внешняя краевая прокрутка реальным курсором в этой фикстуре отключена, чтобы камера не смещалась между записанными шагами. Проверка использует Bevy ButtonInput и состояние кнопок, реальные проекции камеры и раскладку UI; физическая мышь и полный путь обучения проверяются вручную. Результаты текущего прогона записываются в отчёт этапа.
