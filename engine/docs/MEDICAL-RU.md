# Аптечка и лечение Джона

После шести охранников AI_SMG возьми аптечку возле выхода: ЛКМ по предмету. Открой инвентарь через Space или ПКМ по Джону. **ПКМ по аптечке** выбирает лечение и меняет курсор на крест; **ЛКМ по строке Джона** применяет аптечку к нему. Можно закрыть инвентарь через Space и щёлкнуть ЛКМ по Джону на карте. ПКМ вне аптечки отменяет выбор. Заряд расходуется после окончания анимации, повторное лечение требует нового выбора. Полное здоровье или отсутствие зарядов не позволяют начать лечение.

Если аптечку перекрывает стена, поверни камеру клавишами Numpad 7/9, чтобы увидеть предмет; выбор сквозь сплошную геометрию отклоняется.

Оружие остаётся в основном слоте. H и новый приказ отменяют незавершённое лечение без расходования заряда. Ctrl+P, окно подсказки и инвентарь приостанавливают действие. Home возвращает аптечку на карту, пять применений и полное здоровье. В меню паузы сохраняются здоровье и состояние аптечки; выход из обучения освобождает ресурс и звук.

## Что читается из оригинала

- MTF `maps/training_final.mtf`: Medical Kit, ID `[1,-554]`, исходная позиция `[6419.84033203125,11132.328125,1210]`, поворот `[0,0,0]`. Модель `ALITSP-Medkit` и текстура загружаются через общий каталог.
- `config/inventory_object_profiles/tools.txt`: `med_kit`, `TOOL_USES 5`, `OBJECT_EQUIP_LOC EQL_NONE`, `OBJECT_AUTO_EQUIP FALSE`, `OBJECT_USE_SAMPLE AUDIO_MEDKIT`.
- Профиль Джона: `HEALTH_MAX 327`, `SKILL Medic 43`.
- Подбор использует уже подключённые callback кадры стоя/в приседе/лёжа. `CET_OBJECT_PICKED_UP:Medical Kit` запускает исходную подсказку `help_combat_13` с задержкой 1000 мс один раз. Отдельная цель `obj_secure_medkit` закомментирована в оригинальном сценарии и не добавляется в список задач.
- `MSEQ_STAND_USE_MEDPAC` использует `bipedal_stand_heal`, затем `NOTIFY_END` и стояние. CROUCH использует `bipedal_crouch_heal` и присед. PRONE в исходном конфиге также использует crouch_heal и завершающий присед: прототип после такого лечения остаётся в приседе. Модель не перемещается по корневой траектории лечебного клипа.
- Исходная подсказка прямо говорит о заминированной аптечке и объясняет ПКМ по предмету, затем ЛКМ по бойцу. Контекст также сверялся с предоставленным локальным видео, без повторного поиска на YouTube.

## Временная числовая модель

В MTF рядом с аптечкой лежит отдельная Enemy_Land_Mine `[1,-640]` на `[6385.91796875,11111.759765625,1210]`, примерно в 0.397 м от неё. Точный код срабатывания мины и формула эффективности Medic пока не восстановлены. Прототип наносит ранение на callback подбора аптечки; отдельные проверка близости к мине, её удаление и взрыв пока не исполняются. **Половина максимального здоровья теряется при первом подборе; одно лечение восстанавливает `max(1, Medic)` HP**, с ограничением по HEALTH_MAX. Для Джона: 327 → 163.5 → 206.5 → 249.5 → 292.5 → 327; остаётся один заряд. Значения явно помечены как прототип в JSON-отчёте. Это не заявление о числовом совпадении с оригиналом. В интерфейсе HP округляются для отображения.

Пока поддерживается самолечение одного управляемого бойца. Взрыв ловушки не имеет отдельного эффекта и звука; ответный ИИ, прочие источники урона, бессознательное состояние, лечение других бойцов, рост навыка Medic и adrenaline ещё не подключены. Аптечка хранится в отдельном разделе текущего инвентаря без экипировки; полная раскладка оригинального рюкзака предстоит.

## Числовой пример

Из папки проекта:

```bash
./scripts/dev.sh cargo run --locked -j1 -p shadow-model-viewer --bin shadow-map-viewer -- \
  --game-dir "/путь/к/Shadow Company" --player on \
  --player-action medical --player-seconds 360 --player-json /tmp/shadow-medical.json
```

Пример проходит цепочку обучения до AI_SMG, затем подбирает аптечку и лечит Джона. Подсказки автоматически подтверждаются только в числовом примере. `--medical-smoke-json /tmp/shadow-medical-window.json` — проверка окна; ей нужен завершённый участок UZI (`--player-action smg --player-seconds 300`). Обычный запуск обучения не пропускает предыдущие этапы.

Основной код — `medical.rs`; здоровье и зарядность отделены от выбранного оружия и проверяются на завершении действия. Результаты проверок текущего этапа сохранены в `shadow-training-medical-validation.json` вне переносимого исходного проекта.
