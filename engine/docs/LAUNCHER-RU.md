# Подключение к OpenSC Launcher

Движок находится в `engine/` репозитория [STG-44/opensc](https://github.com/STG-44/opensc), рядом с существующими лаунчером и сервером. Подробности: [интеграция и выпуск](../../docs/ENGINE-INTEGRATION-RU.md).

Лаунчер 0.3.0 запускает `shadow-game --game-dir PATH --settings FILE --overrides PATH`.
Настройки и улучшения находятся вне каталога обновляемой версии. Для лаунчера 0.2.0
сохранён синоним `--data PATH`. Подходят и каталог установленной игры, и сама `Data`.

Пакет содержит текущий движок, управление, сведения о сборке и лицензии зависимостей.
Оригинальные архивы и пользовательские данные в раздачу не входят. Подготовка выпуска
использует существующий `manifest-v1.json`, отдельные файлы по платформам и SHA-256.
Подпись манифеста и докачка ещё не реализованы; сейчас используется доверенный HTTPS.

Новый workflow готовит пять нативных пакетов. Сборки и работу окна на каждой платформе
следует подтверждать отдельно; предыдущие игровые прогоны выполнялись на CachyOS.
