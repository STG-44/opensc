# Engine test candidate — 2026-11-05

This candidate packages the locally validated environment and Hummer work.
It is prepared for the Test channel; it does not promote Stable.

- Retain the installed Hummer silhouette and interaction proxy with a repainted
  atlas, readable markings, door details and glass reflections.
- Align open headlight bezels and lenses to measured atlas contours; beam
  origins follow the lens geometry.
- Mount physical windshield wipers on the upper rail. Shared environmental
  conditions control rain sweeps, night headlights, rear position lamps and
  daylight braking lamps.
- Include owned tree, fence, wire and masonry replacements with the engine.
  Custom overrides keep priority; original archives remain external.
- Run radar exploration on an asynchronous snapshot job and reduce repeated
  animation/picking work. Cross-device performance still needs user testing.

The training mission remains daytime and dry. Diagnostic environmental states
exercise the vehicle equipment; full sky, precipitation, storms and continuous
time-of-day rendering are subsequent work. Window reflections are painted;
transparent interiors and live reflection probes are not implemented.

Local validation includes 300 game tests, five geometry-tool tests, strict
25,201-sample gameplay comparison, driving/braking input and day/night/rain
captures. Publication additionally requires the native-platform CI packages,
payload checksum verification and an isolated launcher installation.
