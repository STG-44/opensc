Перед установкой. Тестовая сборка macOS подписана локально, без заверения Apple: открытие может потребовать подтверждения в системных настройках. Сборка Windows не подписана. Ресурсы оригинальной игры в архивы не входят.

02 / Начало работы

Подготовиться к возвращению.

  1. 01

    Распакуйте лаунчер

    Скачайте архив для своей системы, распакуйте его и откройте приложение OpenSC.

  2. 02

    Укажите ресурсы игры

    Выберите папку Data из своей установленной копии Shadow Company: Left for Dead.

  3. 03

    Дождитесь движка

    Когда движок будет опубликован, его можно будет загрузить через лаунчер. Сейчас доступна подготовка ресурсов.
