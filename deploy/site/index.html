Контрольные суммы SHA-256 Для проверки целостности скачанного файла.

macOS: локальная подпись (ad-hoc), без Developer ID и заверения Apple. Система может запросить подтверждение открытия в настройках. Windows: сборка не подписана. Linux x86_64: требуется glibc 2.39 или новее. Для AppImage разрешите выполнение файла в его свойствах; пакеты устанавливайте через менеджер своей системы. Движок загружается лаунчером; оригинальные игровые данные нужно выбрать на своём компьютере. Игровое окно проверено на CachyOS; для Windows и macOS выполнены сборка и автоматические тесты. Полная кампания ещё разрабатывается.

03 / Начало работы

Три шага до готовности.

Для работы понадобятся ресурсы вашей оригинальной копии игры.

  1. 01

    Установите лаунчер

    Скачайте установщик для своей системы и откройте OpenSC. На Linux выберите AppImage или пакет для своей системы. Доступны и переносные архивы.

  2. 02

    Выберите ресурсы

    Укажите папку Data из установленной Shadow Company: Left for Dead.

  3. 03

    Запустите обучение

    Дождитесь загрузки обновления, нажмите «Запустить игру» и выберите обучение в главном меню.
