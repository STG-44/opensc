# Публикация OpenSC на существующем сервере

Страница `site/index.html` предназначена для `https://shadow-test.zaikinagroup.ru/`.
Она работает как статический HTML без Node.js, внешних шрифтов и JavaScript.
Traefik, DNS и сертификат уже настроены; для этой публикации нужен доступ к папке,
которую раздаёт существующий веб-сервер.

Сайт опубликован 16 октября 2026 года. Корневая папка на сервере:
`/mnt/data/shadow-company/public`. Контейнер `shadow_company_files` подключает её
в `/srv/shadow` только для чтения; изменение файлов на хосте не требует перезапуска
контейнера. Конфигурация сайта находится в `/opt/shadow-company/nginx.conf`.
Резервная копия перед первой публикацией хранится вне публичной папки, в каталоге
`/mnt/data/shadow-company/deployments/opensc-0.1.0-4xgScYP9/backup-before.tar.gz`.

## Файлы раздачи

В каталоге сайта должны находиться:

```text
index.html
downloads/
  opensc-launcher-0.1.0-macos-aarch64.zip
  opensc-launcher-0.1.0-macos-x86_64.zip
  opensc-launcher-0.1.0-windows-x86_64.zip
  opensc-launcher-0.1.0-linux-x86_64.tar.gz
  SHA256SUMS.txt
  build-info.json
updates/
  index.html
  manifest-v1.json
```

Архивы лаунчера не содержат движок или оригинальные ресурсы игры.
`updates/manifest-v1.json` пока содержит `release: null`: это манифест будущего
выпуска движка, а не файл со ссылками на лаунчер.

Сборки 0.1.0 получены из успешно завершённого
[запуска Build launcher #3](https://github.com/STG-44/opensc/actions/runs/38935926920),
исходный коммит `8090853f9d37f6a975ef710a77bd3a05a00695da`.
Перед подготовкой раздачи SHA-256 внешних ZIP-артефактов сверены с GitHub.
Каждый артефакт содержит один готовый архив; публикуется именно внутренний архив.
SHA-256 публикуемых файлов и размеры указаны в `downloads/build-info.json`.
Сами двоичные файлы и вычисленные для них метаданные исключены из Git.

## Обновление работающей раздачи

1. Определить корневую папку существующего сайта и сохранить её резервную копию.
   Если сайт работает в контейнере, проверить его bind mount или volume.
2. Загрузить содержимое `downloads/`, сверить SHA-256 на сервере.
   Имена файлов версий сохранять неизменными. Другие файлы раздачи не удалять.
3. Если манифеста ещё нет, положить `updates/manifest-v1.json` из этого каталога.
   Уже опубликованный манифест движка не заменять пустым.
4. Загрузить HTML во временное имя рядом с действующим `index.html`, затем
   переименовать его в `index.html`. Так кнопки станут видны после загрузки архивов.
5. Проверить главную страницу по HTTPS, все четыре загрузки, контрольные суммы
   скачанных файлов и JSON манифеста. Убедиться, что HTTP перенаправляет на HTTPS.

Готовый архив раздачи `opensc-site-0.1.0.tar.gz` содержит эту структуру.
В нём нет конфигурации Traefik, ключей доступа или ресурсов оригинальной игры.
Не распаковывать архив поверх неизвестной корневой папки без проверки её назначения.

## Подпись приложений

macOS-приложение имеет ad-hoc подпись без Developer ID и нотариализации Apple;
Windows-приложение не подписано. Это обозначено на странице как тестовый выпуск.
Сборки и тесты прошли на всех четырёх целевых платформах. Linux-архив собран на
Ubuntu 24.04; совместимость с другими дистрибутивами отдельно не проверялась.
