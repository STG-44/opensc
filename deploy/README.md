Лаунчер не содержит движок и игровой набор данных для запуска. Из переданных
ресурсов игры используется декоративная карта для оформления сайта и окна.
При первом размещении `updates/manifest-v1.json` содержал `release: null`. Сейчас в нём опубликован выпуск движка; установщики лаунчера находятся отдельно в `/downloads/`.

Сборки 0.2.0 получены из успешно завершённого
[запуска Build launcher #4](https://github.com/STG-44/opensc/actions/runs/38971704860),
исходный коммит `b9813dadda27117e2ca607ea979d1bde8a1029d1`.
Перед подготовкой раздачи SHA-256 внешних ZIP-артефактов сверены с GitHub.
Каждый артефакт содержит готовые установщики и архивы; публикуются внутренние файлы.
SHA-256 публикуемых файлов и размеры указаны в `downloads/build-info.json`.
Сами двоичные файлы и вычисленные для них метаданные исключены из Git.

## Обновление работающей раздачи

1. Определить корневую папку существующего сайта и сохранить её резервную копию.
   Если сайт работает в контейнере, проверить его bind mount или volume.
2. Загрузить содержимое `downloads/`, сверить SHA-256 на сервере.
   Имена файлов версий сохранять неизменными. Другие файлы раздачи не удалять.
3. Если манифеста ещё нет, положить `updates/manifest-v1.json` из этого каталога.
   Уже опубликованный манифест движка не заменять пустым.
4. Загрузить HTML во временное имя рядом с действующим `index.html`, затем
   переименовать его в `index.html`. Так кнопки станут видны после загрузки архивов.
5. Проверить главную страницу по HTTPS, все десять загрузок, контрольные суммы
   скачанных файлов и JSON манифеста. Убедиться, что HTTP перенаправляет на HTTPS.

Для обновления нужно получить успешные CI-артефакты и подготовить
`SHA256SUMS.txt` и `build-info.json` с исходным коммитом и результатами проверок.
Карты, снимок окна и загрузки публикуются до атомарной замены главной страницы.
Старые файлы 0.1.0 сохраняются. В архиве раздачи нет конфигурации Traefik или ключей доступа.
Не распаковывать архив поверх неизвестной корневой папки без проверки её назначения.

## Подпись приложений

macOS-приложение имеет ad-hoc подпись без Developer ID и нотариализации Apple;
Windows-приложение не подписано. Это обозначено на странице как тестовый выпуск.
Для 0.2.0 прошли проверки DMG на обоих типах Mac, тихой установки и удаления Setup.exe,
запуска AppImage, распаковки DEB и установки/удаления Arch-пакета через pacman в контейнере Arch Linux.
Linux-сборки требуют glibc 2.39 или новее. Формат `.pkg.tar.zst` предназначен
для CachyOS и Arch Linux; DEB — для современных Debian/Ubuntu.
